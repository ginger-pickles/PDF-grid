# Feedback Control Testing System

**Recursive human+machine interface for agent-supervised development**

## Architecture

```
Human/Agent ←→ supervisor.html ←→ tester-interface.spec.js ←→ tester.html ←→ index-2.html
              (review sessions)    (agent operates)            (A/B/C test)   (rewrite)
```

## Quick Start

### 1. Run the Agent Test

```bash
# Start HTTP server (if not already running)
python3 -m http.server 8000 &

# Run agent test
npx playwright test tests/feedback-control/tester-interface.spec.js

# Organize results
node tests/feedback-control/organize-results.js
```

### 2. Review Results (Human)

```bash
# Open supervisor in browser
open http://localhost:8000/supervisor.html
```

**Or review programmatically (Agent):**

```bash
# Agent checks results without Playwright
curl http://localhost:8000/tests/feedback-control/latest-session/supervisor-summary.json

# Decision logic
jq -r '.agent_decision' latest-session/supervisor-summary.json
# Output: "continue" | "investigate" | "rollback"
```

## Files

- **`tester-interface.spec.js`** - Playwright test where agent operates tester.html
- **`organize-results.js`** - Moves Playwright artifacts to latest-session/
- **`latest-session/`** - Most recent test session output
  - `video.webm` - Recording of agent operating tester.html
  - `trace.zip` - Playwright trace (open with `npx playwright show-trace`)
  - `metrics.json` - Extracted A/B/C comparison data
  - `session-metadata.json` - Test status, duration, log
  - `console-logs.json` - Console output from all versions
  - `supervisor-summary.json` - Machine-readable summary (auto-generated by supervisor.html)
  - `screenshot-*.png` - Key moments during test

## Workflow

### Human Workflow

1. Agent makes changes to `index-2.html`
2. Agent runs `npx playwright test tests/feedback-control/tester-interface.spec.js`
3. Human opens `supervisor.html` in browser
4. Human watches video, reviews metrics, checks for regressions
5. Human approves or investigates

### Agent Workflow (Fully Automated)

```bash
# 1. Make changes
vim index-2.html

# 2. Test changes
npx playwright test tests/feedback-control/tester-interface.spec.js
node tests/feedback-control/organize-results.js

# 3. Check results
DECISION=$(curl -s http://localhost:8000/tests/feedback-control/latest-session/supervisor-summary.json | jq -r '.agent_decision')

# 4. Act on decision
if [ "$DECISION" = "continue" ]; then
  git commit -m "Refactor: no regressions"
elif [ "$DECISION" = "rollback" ]; then
  git revert HEAD
else
  echo "Manual review required"
fi
```

## Test Customization

Edit `tester-interface.spec.js` to test different scenarios:

```javascript
// Change PDF
await page.selectOption('#pdfSelect', 'large-file.pdf');

// Change action
await page.selectOption('#actionSelect', 'zoom'); // or 'pan', 'navigate'

// Test specific version only
await page.uncheck('#syncActions');
```

## Viewing Detailed Traces

```bash
# Interactive timeline with click visualization
npx playwright show-trace tests/feedback-control/latest-session/trace.zip
```

## Principles

1. **Agents use the tools they develop** - Agent operates tester.html exactly as human would
2. **Browser is universal interface** - Everything accessible via web browser
3. **Dual output** - Human visual dashboard + machine-readable JSON
4. **Recursive supervision** - Each layer can be operated by human or agent
